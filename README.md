# Huang Lab protein-candidate triage demo

An application-specific exploratory analysis prepared by Cathy Liu for the
Possu Huang Lab. The site uses the published ADAPT-M source data and two
example conformers from the lab's Caliby repository to make a transparent
candidate-selection workflow.

The public site is static. Rebuild `data.js` from the checked source material
with:

```bash
python3 ../../huang-lab-demo-source/prepare_demo_data.py
```

This is a user-directed, one-role exception to the formal application-demo
gate. It demonstrates quantitative analysis, protein-design interpretation,
and assay/QC reasoning; it is not evidence of molecular-cloning or recombinant
protein-production experience.
