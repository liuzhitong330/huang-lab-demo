# Recipient-value brief

- **Lab decision:** which enriched binders deserve scarce expression,
  purification, and orthogonal-validation capacity?
- **Useful output:** an auditable shortlist whose affinity, dissociation,
  enrichment, replicate, SEC, and conformer-sensitivity evidence can be checked
  separately.
- **Added contribution:** the tool turns reported measurements into an editable
  experimental handoff and makes conflicts visible, such as strongest affinity
  versus cleaner SEC trace shape.
- **Capability shown:** quantitative protein-assay interpretation,
  chromatography/QC reasoning, and connection between structural design and
  experimental evidence.
- **Next action:** carry a four-candidate panel into parallel expression,
  purification, declared SEC QC, and an orthogonal affinity assay.

Value score: 9/10 (lab relevance 2, useful output 2, meaningful interaction 2,
capability evidence 1, credibility/reproducibility 2). The capability score is
kept at 1 because this application demo was prepared with assistant support and
does not independently prove hands-on cloning or protein-production skill.

Formal gate status remains `APPLICATION_DEMO: NO`; this build is a
user-directed, one-role exception after the limitation was disclosed.
